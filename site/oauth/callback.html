REYZ Ops — 問い合わせフォームの送信専用ユーザー

送信専用ユーザーの同意

送信専用ユーザー として Google に同意し、問い合わせフォームの送信権限（Gmail 送信のみ）を更新します。

ログイン画面ではこのユーザーでログインします（他の口座で同意しても、後続の検証で拒否され保存されません）。

同意を開始する

同意コードを受け取りました。

  1. GitHub Actions「oauth-consent」を開く
  2. 右上の Run workflow → code にコピーしたコードを貼る → 緑の Run workflow
  3. workflow が口座を検証し、Secret を更新して配備します。結果は run の Summary に出ます

このコードは数分で失効し、1 回しか使えません。使えなかったら「同意を開始する」からやり直してください。

注意: この画面を開いた端末と同意を始めた端末が違うようです（state 不一致）。自分で始めた同意であれば問題ありません。
