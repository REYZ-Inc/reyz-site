# REYZ サイトの共通背景

更新日：2026-11-27（日本時間）

## 目的と範囲

CEOの指定画像を参考に、コーポレートサイトの背景を、暗い地に大きくぼけた光が広がる表現へ変更する。青い光はREYZピンク `#F715AC` に置き換える。最後の指示で対象は「サイト背景」に限定されているため、画像内の設定ダイアログ、文言、スイッチ、チェックボックスを移植しない。

画像で観察できる特徴は、暗い上部、左右非対称の大きい光、明瞭な輪郭のないグラデーションである。中央部分はパネルで隠れており、元画像の中央背景を実測したとは扱わない。本文の読みやすさを保つため、中央を暗くすることは今回の設計判断である。

## 実装

- 正本は `site/assets/site.css`。固定された装飾専用の疑似要素に複数の静的グラデーションを描画する。
- 基底色は `#0A0A0A`、主な光は `#F715AC`、光の柔らかい部分に `#FAFAFA` を用いる。
- 装飾は `pointer-events: none` とし、リンク・入力欄・メニューの操作を遮らない。内容の前面には置かない。
- 共通背景を隠していたページ全面の不透明な背景だけを透明にする。カード、フォーム、メニュー、写真、動画、PDF表紙の表示面は維持する。
- 小さい画面では光の幅を調整する。固定疑似要素を使い、モバイルの `background-attachment: fixed` に依存しない。
- 新しい画像、動画、外部サービス、JavaScript処理、アニメーションは追加しない。
- 既存の小さいピンク文字と重なる位置でも読めるよう、背景レイヤーの不透明度を広い画面で0.30、820px以下で0.40に抑える。合成色の設計計算と実画面の確認を区別する。
- 既存の文言、URL、ロゴ、文字組み、操作、問い合わせの送信先を変更しない。
- 印刷・強制配色では装飾を非表示にする。

## 反映と検証

`python3 build/build.py` で共通CSSの内容ハッシュ付きファイルと、各ページの参照を再生成する。旧ハッシュ資産は保持する。PRの既存必須チェックを維持し、合否条件を緩めない。

変更前後の生成HTMLを照合し、CSSのハッシュ付き参照以外の文言・構造が不変であることを検査する。デスクトップと狭い幅で背景、文章、メニュー、フォーム、マニュアルの表示を確認する。検証結果はPRに記録し、実行前に合格とは扱わない。iPhone等の実機とブラウザー内の幅変更を区別する。
