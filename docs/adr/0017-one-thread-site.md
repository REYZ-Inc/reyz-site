# ADR-0017: サイトの全要素を、ひとつの ∞ の上に置く

状態: 提案（二席合意と CEO の Yes で採用）

## 文脈

2026-11-20、CEO は main `54e5928` の検証結果を受け、全てのページ・素材・文章・構造・リンク・文脈・デザインが繋がっていること、目的なく掲載しないこと、REYZ のサービスを使いたいと感じさせ、他より良いことを視覚で伝え、問い合わせにつなげることを指示した。

検証で次を確認した（詳細は [site-coherence.md](../site-coherence.md) 2 章）。∞ の形が 3 種類ある。実写と CG が事業構造と結び付いていない。隣の事業・料金・相談へ進む本文リンクを持たない節が 4 つある。料金へ進む本文リンクが無い。Home 冒頭の映像は、ADR-0015 がブランド表現として採用し ADR-0016 が新しい形で作り直したものだが、DEC-20260926-03・04 の「全てが繋がっていく」とは連続していない。録画単体とスクロール連動を比べて前者を選んだ理由は、記録で確認できない。

## 選択肢

1. 指摘ごとに個別に直す（素材の差し替え、リンクの追加）。
2. 外部の受賞サイトの構成・演出を取り入れて作り直す。
3. REYZ の事業構造（クリエイター ― REYZ PLATFORM ― 企業）を ∞ の形に対応させ、全要素をその上に置く規則と関門を定め、段階的に是正する。

## 決定

3 を採用する。

- ∞ は 1 つの形（一枚のリボン）とし、左の輪をクリエイター、右の輪を企業、交点を REYZ PLATFORM とする。
- 要素を足す・残すときは「位置・目的・受け・渡し」の 4 つを編集上の判断基準にする。CI は、宣言した導線のリンク先が実在することと、主要な操作を完了できることを検査する。全節に内部リンクを求めることはしない。
- 「他より良い」は、読者が自分で確かめられる REYZ の事実を冒頭から 1 操作に置くことで伝える。根拠を併記できない比較は載せない。
- 是正は段 0（現状と指標の記録）から段 5 までに分け、各段を独立した PR とする。D1〜D3 に依存する作業は、その判断の後に進める。

1 は同じ断絶を別の場所に作る。2 は REYZ の事業構造と決定台帳から離れ、借り物になる。

## 帰結

- ADR-0015 の「Home の最初の粒子の ∞ を動画へ置き換える」を、D2 が採用され段 3 を実施するときに更新する（リボンから粒子へつながる構成）。
- ADR-0016 の 7 本の帯（Contour）は、D1 で一枚リボンが採用された場合に段 3 で廃止する。旧 URL は新作へ対応付ける。
- 導線を足すときは宣言に書き、リンク先の実在を検査が確かめる。
- 段 0（計測）と段 5（自社撮影）は、CEO 側の方式と素材の判断を前提とする。
