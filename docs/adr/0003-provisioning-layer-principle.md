# 0003 宣言は自社、事業者は差し替え可能な adapter（プロビジョニング層の原則）

- 状態: 採用（2026-09-28）
- 決定者: ロウ（CEO）／起案: IV

## 文脈
今後、多数の顧客サイトを制作し、ドメイン・DNS・証明書・フォーム・メールを REYZ が代行運用する。特定の事業者（Cloudflare、Google、GitHub）への依存が固定化すると、事業者の方針変更や障害が REYZ と顧客の実害になる。

## 決定
- 何を置くか（レコード・設定・受付の方針）は REYZ が宣言として所有し、リポジトリに置く
- 事業者への反映は adapter（`cf_dns.py`、Worker、workflow）が行い、事業者を替えるときは adapter だけを替える
- 顧客のドメインは顧客が所有し、REYZ は運用する（Cloudflare Self-Serve Agency Program を既定、顧客アカウントへの管理者招待を代替）
- 事業者から抜けられることを確認する「exit test」を関門に含める（初の顧客サイトで実装）

## 帰結
- 設計書・ADR に「意図的に含めないもの」と「発動条件つき項目」を明記する慣行
- 過剰な先行実装をしない（発動条件を満たすまで作らない）
